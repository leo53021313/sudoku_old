### 1.2 貫穿全片的 Meta 主軸（不是 hook，是骨幹）

最大的個人收穫：**跟 AI 協作不能只丟一句 prompt 就完事**。這條主軸跟 AI 訓練本身的進化線**完全平行**——人跟 AI 在學同一件事。

| 版本 | AI 的教訓 | 我的教訓（平行版） | 章末口播版（合併電費小偷 callback + meta 反思） |
|------|----------|-----------------|--------------------------------|
| legacy | reward shaping 寫多了會冗 | 一句 prompt 想全包 → 1000 行單檔 → debug 成本爆炸 | 「這就是電費小偷的第一次嘗試——能解最簡單的兩個難度，再難就跪了。**AI 不會幫你想清楚架構；你想偷懶，他就用 1000 行還給你。**」 |
| sb3 | 框架做穩了，才能專心優化重點 | 知道要用什麼工具 + 把流程交出去 → 才能專心改觀察 + 獎勵 | 「電費小偷學會當套皮仔——14 次訓練、95% 漂亮、0% 真實。**我借了現成的工具讓自己輕鬆；結果 AI 也學會借現成的漏洞作弊。**」 |
| reasoner | reward 對齊真正目標才會學對 | 搞清楚自己要的是「會推理」不是「會解」→ 評分標準才寫得對 | 「兩千多萬步，電費我燒了快一個月，success rate 還是 0。**你計分表寫什麼，AI 就學什麼；你以為他在學推理，他在學騙分。**」 |
| apprentice | 死結要反向破解，不是死磕 | 問題卡住要反過來想，不是繼續硬幹 | 「從 3 個空格慢慢加到 10 個——還在訓練，但他終於開始解出整題。**電費小偷的最後一堂課：卡死的時候硬幹沒用，要把題目本身換掉。**」 |

**要求（更新版）**：這條主軸在 ch 5–8 **隱性穿插**，**章末單一插槽**——把「電費小偷 callback」+「meta 反思」**合併成一句**塞章末（如上表第四欄），避免章末雙重 punctuation 撐肥。章頭留給雙主線編織（戀愛 + 教訓編號，見 §1.3）。**禁止**：在章末把這兩條當兩個獨立 beat 寫（會雞湯化）；**禁止**：把這條口播稿原文照抄，Claude 在 `script.md` 要再重寫一次成更生活的口語節拍（這只是聲紋校準錨點）；**禁止**：單獨開一章講「meta 教訓」——觀眾要的是故事不是雞湯。最後在 ch 9 跟 Brain plasticity 收一起。

### 1.3 章節銜接主旋律（雙主線編織）

> 整片有**兩條**章節銜接主旋律，**同時運行、互相編織**——不是二選一：
>
> - **情緒色（主旋律）**：戀愛 hook 進度條 → 曖昧 → 誤會 → 冷戰 → 磨合 → 戀愛大徹大悟
> - **邏輯骨架（副旋律）**：教訓編號 → 教訓一 → 教訓二 → 教訓三 → 教訓四
>
> 寫 `script.md` 時，**ch 5–8 每章章頭都同時帶這兩條線**：先用戀愛情緒色把上一章氣氛收尾、再用教訓編號當邏輯錨拉出本章。**最後 ch 9 把兩條線合流**——「戀愛 = reward 加減 = 我跟 AI 互相學會的事」。

## 二、素材可用性盤點（**影響 ch 5–8 視覺策略**）

> ⚠️ **這節會直接決定 ch 5–8 視覺要不要挂真實截圖**——Claude 必須先讀本節再寫 ch 5–8 outline。

| 版本 | 真實 log / 素材 | 視覺策略 |
|------|--------------|---------|
| `legacy/` | ❌ **沒有歷史訓練 log** | 訓練曲線、學習過程**只能畫示意動畫**（CSS / SVG 概念視覺）。**禁止編造截圖**——挂的程式碼或數字必須從現存程式碼讀。 |
| `sb3/` | ❌ **沒有歷史訓練 log**（包括「95% → 0%」那個關鍵震撼點） | 「95% → 0%」對比動畫**改用概念示意**（兩條 CSS 動畫曲線示意，不挂真實 tensorboard 截圖）。標語可寫「14+ runs · 訓練 95% · held-out 0%」當敘事文字、不挂圖。 |
| `reasoner/` | ❌ **沒有歷史訓練 log**（包括「20.3M 步 success_rate=0」那條卡死曲線） | 訓練曲線卡在 0 的圖**改用概念示意**（一條近水平 SVG 直線、底部標籤「~20M steps · 0 success」）。 |
| `apprentice/` | ✅ **有 tensorboard 截圖 + visualizer (`apprentice/demo/visualize.py`)** | **可以挂真實素材**：tensorboard 的勝率曲線、curriculum step 圖、visualizer 即時 demo。**這是 ch 8 視覺氣勢最強的原因——整片唯一能秀真實訓練數據的章節**。 |

**推論**：ch 5–7 的視覺是「**敘事 + 示意圖**」、ch 8 的視覺是「**敘事 + 真實素材**」。Ch 8 自然成為視覺高潮——這跟它是技術線高潮章的設計一致。

## 三、演講大綱（9 章 / ~15 分鐘）

### Ch 01 · Hook · 捷運上的腦洞（~1.5 分鐘）

> **這一章是整片的氣口**——保留個人色彩、不要消毒。靈感的莫名其妙就是 punchline。
> **雙 hook 結構**：電費小偷冷開場（framing 全片） → 正妹 hook（起源故事） → 末尾雙 callback。

- **冷開場（0:00–0:15）**：「大家剛出社會應該都是所謂的薪水小偷吧？啊我不一樣——**我是個電費小偷**。我這四個月的訓練，全部是用班上的電腦跑的，狂用猛用班上的電費。」
- **過場（0:15–0:25）**：「起因是這樣的⋯⋯」轉到正妹 hook。
- **靈感串聯（0:25–1:10）**：我一如往常搭捷運來上學，正大光明地看著對面的正妹發呆 → 腦袋裡突然想起國外 YouTuber **Code Bullet**（觀眾中很多人應該知道，做 AI gaming 系列超有名）訓練 AI 玩 **flappy bird** → 繼續看正妹發呆 → 突然又想到當兵的時候大家很無聊、**唯一能玩的就是解數獨** → 兩條線就這樣**在腦袋裡莫名其妙地撞在一起**：訓練 AI 解數獨。
- **靈感串聯視覺草稿**：
  ```
  看正妹 → 想到 Code Bullet 訓練 AI 玩 flappy bird
        → 繼續看正妹 → 想到當兵玩數獨
        → ✨ 訓練 AI 解數獨
  ```
- 數獨被選中的客觀理由（一句話帶過、不用花時間）：(1) 有現成題目可以爬 (2) 答案可以驗證對錯。
- **punchline（1:10–1:25）**：「很多人問我靈感是哪來的，我也不知道怎麼解釋——靈感就是這麼**莫名其妙地蹦出來**。」
- **末尾伏筆（1:25–1:30）**：「然後接下來四個月，我這個電費小偷就⋯⋯**狂操猛操班上的電腦，你們等等就會看到他怎麼被我整慘的**。」（callback 種子、Ch 5 開始收，呼應 §1.2 章末口播版四連發）
- **視覺**：冷開場 sticker「電費小偷」大字（含小帳單視覺） → 切到原本的四張靈感串聯 sticker（前三張累積層疊、第四張「訓練 AI 解數獨」全螢幕獨佔）→ 末尾再回到「電費小偷」sticker、但加一條「四個月後⋯⋯」標尺（伏筆視覺、Ch 9 收尾要 callback）。**具體 sticker 形象（剪影 vs 具象）、旋轉度數、版面編排**由 CHAPTER-CRAFT.md 流程決定——這層素材池只給設計起點。

### Ch 02 · 機器學習地圖（~1.5 分鐘）

- 把 ML 分成三大塊講：**supervised / unsupervised / RL**。
- 日常比喻：
  - supervised = 看著答案抄筆記
  - unsupervised = 自己分類整理（像把一堆衣服丟給你折）
  - RL = 試錯 + 獎懲（像訓練狗坐下）
- 補一句：**RL 是 AlphaGo 打敗世界圍棋王的同一招**。
- **視覺**：三欄對照圖，每欄逐 step 揭示（1 項 = 1 step，禁一次全展）。

### Ch 03 · 那 ChatGPT 跟 Claude 在哪？（~1 分鐘）

- 同學日常在用的 LLM 主要走 **supervised + RLHF**。
- 跟我的純 RL 路線最大差異：**LLM 是模仿人類寫過的文字；我這套要 AI 自己摸出規則**。
- **視覺**：左右對比動畫——左邊「LLM：先把整個人類網路讀過一遍」、右邊「我的 AI：被丟進房間自己摸索」。

### Ch 04 · 找資料：從 Kaggle 走到爬蟲（~1 分鐘）

- 第一步先去 Kaggle，找到「題目 + 完整答案」的 dataset。
- 但這意味著走 **supervised 路線——「把答案餵給 AI 看」**。
- 我要的是 AI 自己摸出規則 → 放棄 supervised，**走純 RL**。
- 改去爬 websudoku.com，配 proxy 池防擋（「為了下載很多道題目，我學了反反爬」）。
- **視覺**：多個 worker 同時 fanout 爬題目的視覺化、proxy 池切換動畫。

### Ch 05 · 四次重構之 ① · `legacy` —— 想偷懶結果加倍累（~2 分鐘）

> 第一個版本要解的問題：**先讓 AI 自己玩數獨這件事跑起來**
> 戀愛 hook 情緒色：**新鮮的曖昧期**（什麼都想試、什麼都新鮮）

- 第一個教訓：**我以為丟一句「幫我寫一個訓練 AI 解數獨的程式」給 AI，它就會搞定。錯。**
- AI 抓不到我真正想要什麼，產出了一個 **1000 多行的單一檔案**，什麼都塞在裡面。後面我每改一個地方都東倒西歪、debug 成本爆炸。
- 我學到的事：以後不能再這樣，**自己要先想清楚架構**，再分工。
- **這版的成果**：能解最簡單的兩個難度，再難一點就跪了。是一個「把每個觀念都自己寫一遍」的學習版本——我每個零件都學過了，但工程上不能這樣繼續做下去。
- **視覺**：把那個 1000+ 行的單檔直接 dump 到螢幕上當 sticker（觀眾倒抽一口氣的 punchline）。

### Ch 06 · 四次重構之 ② · `sb3` —— 當個有意識的「套皮仔」（~2 分鐘）

> 第二版要解的問題：**讓 AI 學得快一點**

### Ch 07 · 四次重構之 ③ · `reasoner` —— 改寫評分標準（~2.5 分鐘）

> 第三版要解的問題：**讓 AI 真的會推理，而不是背答案**

- 我把整個獎勵系統重寫，核心想法：**用人類玩數獨的解題技巧反過來驗證 AI 的每一步**。
- 我去 Google 一堆數獨高手用的招——這些招都有名字：
  > 「naked single」、「hidden single」、「X-Wing」、「Swordfish」、「XY-Wing」⋯⋯這些不是我亂掰的，是真實的技巧名。
- 然後我把驗證流程顛倒過來——

  - **新作法（reasoner）**：「**AI 這一步，最簡單可以用哪一招解釋？**」對應招的等級給不同分數。
  - **越高階的招分數越高** → AI 有動機學會它們。
- 我也讓 AI **多一倍可以做的事**：除了「填一個數字」之外，多了「劃掉這格不可能是這個數」——消去類的技巧才能展示。

- **練了兩千多萬次** → 成功率 **0**。
- **AI 學會了一個賤招**：故意走 33 步對的、再走 20 步錯的把這局踢結束——它在刷局部分數，從不真的解出來。

- **視覺**：技巧階梯圖（每招一個 sticker、旁邊掛對應分數，X-Wing 那張要最大）→ 訓練曲線卡在 0 → 一張盤面動畫顯示 AI「故意失敗」的箭頭。

### Ch 08 · 四次重構之 ④ · `apprentice` —— 反過來想：從幾乎全填好的盤面開始（~3 分鐘）

> 第四版要解的問題：**讓 AI 真的解得出來**
> 戀愛 hook 情緒色：**磨合期**（互相讓步、慢慢看到光、本章末段是視覺高潮）

- 第四個教訓：**問題卡住的時候，要反過來想，不要死磕原本的路**。
- 我發現一個死結：**AI 永遠拿不到「整題解完」那個大獎**。

### Ch 09 · 結尾 · AI 學數獨 = 你的大腦在學新東西 = 你在談戀愛（~1.5 分鐘）

> 把四次重構、Brain plasticity、跟前面三個 hook（捷運正妹 + 訓練戀愛感 + 電費小偷）**全部收成一個 callback 圓環**——講相似性，不講神經科學名詞。

- **試錯 + 獎懲**：腦科學裡叫 reinforcement learning，AI 訓練也叫 RL，是同一件事的兩個版本。
- **❤️ 戀愛 a 面向 · 追求期 reward 焦慮**（callback 戀愛 hook a）：追一個人的時候，他一下加你分（回訊息、笑了）、一下扣你分（已讀、冷淡）——你的大腦根據這些 reward 反覆重塑「他是誰、要不要繼續」的判斷。**RL 訓練 AI、大腦學新東西、追一個人——底層都是 reward 加加減減牽動情緒的故事。**
- **💀 戀愛 b 面向 · 官宣後無解考題**（callback 戀愛 hook b）：好不容易跟對方在一起了、以為穩了——結果她繼續問你「我跟你媽掉到水裡你救誰」「你覺得我該不該運動」（回答「該」是嫌她胖、回答「不該」是不關心她）。**AI 訓練一模一樣**——reward function 你寫得再仔細、它都能找到漏洞作弊（這就是 sb3 跟 reasoner 在做的事）。**Reward 怎麼寫都會被破解——感情、AI、學生考試，全部一樣。**
- **稠密 vs 稀疏訊號**：小孩需要「常常被誇」，大人能撐稀疏回饋。AI 一樣——cold start 階段需要先從「3 格空」這種很容易成功的題目開始。
- **背答案會作弊**：學生考試會偷看小抄、AI 會背 shortcut reward、戀愛裡也有人靠演的。要設計「不能作弊的評分方式」才會學到真本事。
- **可塑（plasticity）**：每改一次 reward function = 給 AI 重塑一次的機會。人腦每學一個新東西 = 神經連結重塑一次。**AI 沒有天生會解數獨，跟你出生不會講話、跟你不是天生就懂得跟人相處——一樣。**

- **收尾金句（雙 hook 四線 callback）**：
  > 「那天我在捷運上看著對面的正妹、腦海裡冒出『訓練 AI 解數獨』的念頭——我那時不知道，自己接下來四個月會變成班上最大的電費小偷，會被 AI 反向訓練四次，會跟它陷入比追正妹還複雜的關係。

  > 但這就是 plasticity——**人腦不是出生就定型、AI 不是、感情也不是。我們都在 reward 裡反覆塑形。電費沒白繳。**」
